## Task 5: Durable cross-device image synchronization

- Upgrade IndexedDB `ch-ultimate-core` from version 1 to 2 and add a Blob store keyed by immutable SHA-256, preserving the gateway snapshot.
- Never store image bytes in the JSON snapshot. `loadSkuImage` checks persistent cache first.
- Automatically prefetch all server-available catalogue images online and foregrounded with concurrency two, restart/reconnect resume, deduplication, pause, retry, progress, and safe quota failure.
- Track server source-image processing separately from each client cache. Prune only unreferenced hashes after an authoritative bootstrap.
- Replace direct `sku.imageUrl` consumers on desktop and mobile with gateway-backed loading.
- Allow desktop and mobile upload/replace. Mobile fixes EXIF orientation, scales longest edge to 1,600 px, and compresses JPEG to at most 5 MiB. Desktop validates supported MIME and 5 MiB.
- Successful upload seeds the local hash. Catalogue commits even when image processing fails; failed URLs remain visible and retryable. Missing source URLs use fallback and are not failures.
- Verify IndexedDB migration, interrupted resume, changed hash, quota failure, fallback, mobile preprocessing, and two-device display.
